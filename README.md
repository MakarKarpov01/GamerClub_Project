GamerClub Forum: Gaming Community Platform

GamerClub Forum is a modern and responsive gaming community platform built with Django. It provides gamers with a place to share gameplay tips, find teammates for multiplayer sessions, or simply discuss their favorite games in an organized way.

Project Overview:

The forum features user registration, allowing users to create accounts. Once logged in, users can create new threads, comment on existing ones, and filter content by categories such as "Guides," "CS2," "Dota 2," "Roblox," "General Discussion" and others

Key Features:

User registration and authentication: Users can register by providing a username and password, and log in securely.
Post creation: Authenticated users can post new posts with titles, text, and optional images. 
Comment system: Each post has its own thread where users can leave comments and respond to each other. 
Categories: Posts are organized into thematic sections, making it easier to navigate through the content. 
Responsive design: The entire application uses Bootstrap v5.x, ensuring a seamless user experience across devices, from desktop monitors to mobile phones. 
Integration with the admin panel: Administrators have complete control over user management, moderation tools, and site settings through the standard Django admin interface.
